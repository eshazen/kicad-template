# KiCad

This is where KiCad projects are stored for this template.

There is a ```default/``` directory that contains the template project, see the <a href="/README.md">main repo README.md</a> for info on how to set it up for your PCB design.

Edit this README.md file to explain the PCB at a high level:
- what it does
- what are its inputs and outputs
- the pinout
- etc.

Be sure to edit the other README files:
- ```/datasheets/README.md```
- ```/calculations/README.md```
- ```/cad/README.md```
